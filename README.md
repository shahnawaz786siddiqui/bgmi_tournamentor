# 🎮 BGMI Tournament App

A complete **BGMI (Battlegrounds Mobile India) Tournament Management App** built using Flutter & Firebase.
This app allows users to join tournaments, track match details, and compete seamlessly.

---

## 🚀 Features

✨ User Authentication (Login / Signup)
✨ Browse Available Tournaments
✨ Join Tournaments with Entry Fee
✨ Live Slot Tracking (Auto Update)
✨ Prize Pool & Per Kill Details
✨ Clean & Modern UI (Gaming Style 🎯)
✨ Admin Panel (Create & Manage Tournaments)
✨ Real-time Database (Firebase Firestore)

## 🛠️ Tech Stack

* **Frontend:** Flutter (Dart)
* **Backend:** Firebase
* **Database:** Cloud Firestore
* **Authentication:** Firebase Auth
* **Notifications:** Firebase Cloud Messaging (FCM)

---

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/bgmi_tournamentor.git
```

2. Go to project folder:

```bash
cd bgmi_tournamentor
```

3. Get dependencies:

```bash
flutter pub get
```

4. Run the app:

```bash
flutter run
```

---

## 🔐 Firebase Setup

* Create a Firebase project
* Enable Authentication (Phone / Email)
* Create Firestore Database
* Add `google-services.json` in android/app
* Add `GoogleService-Info.plist` for iOS
